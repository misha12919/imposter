# Шпион

Веб-игра «Шпион»: одно загаданное слово для всех, кроме одного игрока — он шпион и не знает слово.

## Режимы

- **Одно устройство** — игроки по очереди нажимают кнопку и видят слово или роль шпиона.
- **Несколько устройств** — хост создаёт комнату по коду, остальные подключаются; у каждого своё слово на экране.

## Запуск

```bash
npm install
npm start
```

Откройте в браузере: http://localhost:3000

Для игры с разных устройств все должны быть в одной сети (или сервер доступен по URL). Хост создаёт комнату и передаёт 6-символьный код остальным.

## Правила

Минимум 3 игрока. Ведущий обсуждение — вне приложения: игроки задают вопросы, шпион пытается угадать слово, остальные ищут шпиона.
