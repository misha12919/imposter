# Шпион

Веб-игра «Шпион»: одно загаданное слово для всех, кроме одного игрока — он шпион и не знает слово.

## Сайт (GitHub Pages)

После пуша в `main` сайт публикуется автоматически:

**https://misha12919.github.io/imposter/**

На GitHub Pages работает режим **«Одно устройство»**. Режим с нескольких устройств требует Node-сервера (`npm start`).

## Режимы

- **Одно устройство** — игроки по очереди нажимают кнопку и видят слово или роль шпиона.
- **Несколько устройств** — хост создаёт комнату по коду (нужен запущенный сервер).

## Локальный запуск (с сетевой игрой)

```bash
npm install
npm start
```

Откройте: http://localhost:3000

## Правила

Минимум 3 игрока. Обсуждение ведётся вживую: игроки задают вопросы, шпион угадывает слово, остальные ищут шпиона.
